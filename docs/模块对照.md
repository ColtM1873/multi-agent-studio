# 旧脚本 → 新架构 模块对照表

> 本文档说明：你原来手写的那些模块（`SIAgent_new.py`、`World_function_new.py` 等），
> 在重构后的软件里分别对应哪个文件、哪个函数。方便你之后调整文件结构时快速定位。

## 一、总体对应关系

| 旧文件 | 原功能 | 新位置（文件 · 函数/类） |
|---|---|---|
| `SIAgent_new.py` / `ChatAgent_new.py` | 程序入口：`main_function` + `asyncio.run` + `while True: input()` 对话循环 | `run.py`（入口）<br>`app/services/chat.py` · `ChatManager`（运行时管理）<br>`app/api/chat_ws.py` · `chat_ws`（对话 WebSocket） |
| `World_function_new.py` | 主图 `TheWorld`（Supervisor，含记忆工具、总结/清空、子 agent 挂载） | `app/runtime/graph_builder.py` · `build_world` |
| `sub_agent_sub_graph_factory_new.py` | 子图工厂 `build_sub_agent`（ReAct 循环 + 总结/清空） | `app/runtime/graph_builder.py` · `build_sub_agent` |
| `variant_message_state.py` | state 类：`ExtendedMessagesState` / `DocsState` / `WebSearchState` | `app/runtime/state_factory.py`（改为**运行时动态生成**） |
| `various_subagent_specs.py` | 子 agent 的 spec 字典 + MCP client 构建 | `app/config/models.py` · `SubAgentConfig` / `MCPServerConfig`<br>数据在 `configs/*.json` |
| `vairous_system_prompts.py` | 各 system prompt + `postgres_prefix/suffix` | 数据在 `configs/*.json`（`main_agent.system_prompt`、`sub_agents[].system_prompt`、`postgres.prefix/suffix`） |
| `various_prompts.py` | `summery_promt` + `ReAct_system_prompt` | `app/runtime/prompts.py` |
| `astream_consume_new.py` | `stream_ainvoke` 流式消费（边 print 边写 md 文件） | `app/runtime/streaming.py` · `run_agent_stream`（事件流 → 前端） |
| `view_or_edit_history.py` | thread 列表 / 删除 / 选择（CLI） | `app/services/threads.py`（数据访问）<br>`app/api/threads.py`（REST） |
| `view_or_edit_subgraph.py` | 浏览子图记录（CLI） | `app/services/threads.py` · `list_subgraph_nodes` / `get_subgraph_history_by_node` |
| `view_checkpoint_md.py` | checkpoint → Markdown 渲染 | `app/services/history_render.py` |
| `checkpoint_structure.py` | 样本 checkpoint 结构（调试参考） | （已废弃，仅作调试参考） |
| `output_from_main_agent.py` | 最后一轮结果序列化 dump | （已废弃，GUI 直接从 checkpoint 渲染历史） |
| `folder_of_MCPs/` | 本地 MCP 服务器（彩云天气/高德地图） | （保留未动，可在配置里以 `stdio` 或独立进程方式接入） |

## 二、原来「改一处就要改 7 处」的配置 → 现在的位置

| 原来的散落项 | 现在的位置（config JSON 字段） |
|---|---|
| ① API key（`os.getenv(...)`） | `main_agent.api_key`、`sub_agents[].api_key` |
| ② 主 system prompt | `main_agent.system_prompt` |
| ③ `main_agent_specs` | `main_agent`（含 `llm_provider_name`、`file_tools`、`embedding`、`summary`） |
| ④ `sub_agent_specs_list` | `sub_agents`（数组，每项含 name/description/system_prompt/api_key/llm_provider_name/mcp_servers/state_messages_key/summary） |
| ⑤ 各 agent 模型 | `main_agent.llm_provider_name`、`sub_agents[].llm_provider_name` |
| ⑥ postgres 库名 + 连接串 | `postgres.prefix` / `suffix` / `store_database` / `checkpoint_database` / `store_namespace` |
| ⑦ state class | `sub_agents[].state_messages_key`（**由系统自动生成并锁定**，不再手写 state class） |

其他可配置项：

| 原项 | 现在字段 |
|---|---|
| `SUMERIZE_GAP_TOKENWISE` / `FLUSH_HISTORY_TOKENWISE` / `RESERVE_MESSAGE_ROUND`（主 agent） | `main_agent.summary.*` |
| `FLUSH_HISTORY_TOKENWISE_FOR_SUB` / `RESERVE_MESSAGE_ROUND_FOR_SUB`（子 agent） | `sub_agents[].summary.*` |
| `bge_embeddings`（模型/设备/缓存目录/维度） | `main_agent.embedding.*` |
| `agent_work_dir`（文件工具根目录） | `main_agent.file_tools.root_dir` |
| `stream_output_md_dir` | `output.stream_output_dir` |
| `html_report` / HTML 报告 prompt | `main_agent.html_report` / `main_agent.html_report_prompt` |
| 记忆吸附开关 / 吸附条数（全局） | 系统设置 `configs/settings.json` · `memory_attach` / `num_memories_attached` |
| 回复完成提示音（全局） | `configs/settings.json` · `notification_sound` |

## 三、关键概念映射

| 旧概念 | 新实现 |
|---|---|
| 子图 `checkpointer=True` 挂到父图 | `build_world` 里 `main_agent_builder.add_node(name, subgraph, ...)`，子图由 `build_sub_agent` 返回 `builder.compile(checkpointer=True)` |
| 父子消息通道「消息键唯一、共享键同名穿透」 | `app/runtime/state_factory.py`：主图 `messages`；子图各用唯一的 `state_messages_key`；`subagents_reports_submit` / `instructions_for_subagents` 故意同名用 `merge_dicts` 穿透 |
| 子图历史「按子 agent 聚合」 | `app/services/threads.py::get_subgraph_history_by_node`（兼容 `checkpoint_ns` 有/无 `:task_id` 后缀） |
| `interrupt()` 的 html 报告确认 | `app/runtime/graph_builder.py::query_to_produce_html` + 前端 `askConfirm` 弹窗 |
